# Scopegram for macOS

Scopegram — мой форк официального Telegram для macOS. Это обычное нативное приложение на Swift и Objective-C++, без Electron и внедрения сторонних библиотек в запущенный клиент.

Проект сделан под личное использование. Некоторые функции меняют стандартное поведение Telegram и могут перестать работать после обновлений апстрима. Используйте их на свой риск.

## Что изменено

- просмотр одноразовых и самоуничтожающихся медиа на компьютере;
- сохранение сообщений, удалённых собеседником;
- история редактирования сообщений;
- отключение отправки отметок о прочтении, просмотра историй и набора текста;
- копирование и сохранение контента из чатов с ограничениями;
- скрытие рекламных сообщений;
- подтверждение перед звонком;
- отображение Peer ID и маскирование номера телефона;
- отдельный раздел настроек Scopegram;
- обновление приложения через GitHub Releases вместо официального канала Telegram.

Набор функций и их состояние можно посмотреть в **Настройки → Scopegram**.

## Бейджи Scopegram

В клиенте есть отдельные анимированные бейджи разработчика, официального канала и сторонника проекта. Они не подменяют настоящую верификацию Telegram и не считаются Premium-статусом.

Нативная галка, Premium-эмодзи и бейдж Scopegram отрисовываются и обрабатывают нажатия независимо друг от друга.

Локальные тестовые галки можно назначить по Peer ID в настройках Scopegram. Положительный ID относится к пользователю, `-123` — к группе, `-100123` — к каналу.

## Установка

Готовые сборки публикуются в [GitHub Releases](https://github.com/lonestill/scopeGram/releases).

1. Скачайте DMG для Apple Silicon.
2. Перенесите `Scopegram.app` в `/Applications`.
3. Если macOS блокирует первый запуск ad-hoc сборки, снимите атрибут карантина:

   ```bash
   xattr -cr /Applications/Scopegram.app
   ```

## Сборка

Понадобятся macOS, Xcode 15 или новее, Command Line Tools и Python 3.

Клонируйте репозиторий вместе с сабмодулями:

```bash
git clone --recurse-submodules https://github.com/lonestill/scopeGram.git
cd scopeGram
```

Быстрый вариант использует заранее собранные тяжёлые зависимости:

```bash
sh scripts/download_precompiled.sh
python3 build_scopegram.py
```

Полная сборка зависимостей:

```bash
brew install cmake ninja meson nasm yasm openssl@3 zlib autoconf libtool automake pkg-config
sh scripts/setup_build_env.sh --build
python3 build_scopegram.py
```

Чтобы после сборки сразу запустить приложение:

```bash
python3 build_scopegram.py --run
```

Результат сборки: `Scopegram.app` рядом с исходниками проекта.

## Структура проекта

- `Telegram-Mac/` — приложение, меню и интеграция обновлений;
- `packages/` — интерфейс и функциональные модули;
- `submodules/telegram-ios/` — TelegramCore, Postbox и связанные компоненты;
- `core-xprojects/` — медиа- и сетевые зависимости.
